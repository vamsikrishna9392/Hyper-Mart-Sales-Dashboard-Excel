 🛒 Hyper Mart Sales Dashboard | Microsoft Excel

 📌 1. Project Overview
The Hyper Mart Sales Dashboard is an interactive Excel-based data analytics project developed to analyse sales data and monitor business performance. It transforms raw sales data into meaningful visual insights using Excel features such as Pivot Tables, Pivot Charts, and Slicers.

 🛠️ 2. Tools Used
. Microsoft Excel
. Pivot Tables
. Pivot Charts
. Slicers
. Data Cleaning
. Excel Functions
. Data Visualization

 🔍 3. Key Analysis
. Sales Performance Analysis – Analysed overall sales performance.
. Profit Analysis – Examined business profitability.
. Category-wise Analysis – Compared sales across product categories.
. Region-wise Analysis – Analysed sales performance across regions.
. Quantity Analysis – Examined the quantity of products sold.
. Product Performance – Identified products contributing to sales.

 📊 4. Dashboard Features
. Interactive and user-friendly dashboard.
. Visual representation of sales and profit.
. Category-wise and region-wise sales charts.
. Product performance analysis.
. Dynamic filtering using Slicers.
. Pivot Charts for clear data visualization.

 💡 5. Skills Demonstrated

. Pivot Table Creation
. Pivot Chart Development
. Interactive Dashboard Design
. Data Visualization
. Business Insights Generation
. Analytical Thinking

 📁 7. Project Files

🎯 8. Project Objective
The main objective of this project is to analyse Hyper Mart sales data, understand business performance, identify sales trends, and generate meaningful insights that support better business decision-making using Microsoft Excel.
